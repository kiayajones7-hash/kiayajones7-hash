# Security Incident Documentation

**Status: Planned**

## Objective

Practice clear, structured documentation for a fictional security event involving a user account.

## Concepts Covered

- Incident intake and triage
- Account compromise indicators
- Evidence preservation
- Escalation and communication
- Containment and recovery concepts

## Lab Plan

1. Write a fictional incident scenario involving suspicious account activity.
2. Create a timeline using clearly labeled fictional events.
3. Document initial triage questions and relevant evidence to collect.
4. Outline appropriate escalation and containment considerations.
5. Write a concise incident summary and lessons learned.
