# Identity Governance and Access Reviews

**Status: Planned**

## Objective

Show how periodic access reviews can identify unnecessary, outdated, or inappropriate access.

## Concepts Covered

- Identity Governance and Administration (IGA)
- Access reviews and recertification
- Ownership and approval
- Excessive or dormant access
- Remediation and audit evidence

## Lab Plan

1. Create a fictional access review scenario and sample user-access list.
2. Define review frequency, reviewer responsibilities, and decision criteria.
3. Identify sample access that should be retained, changed, or removed.
4. Document remediation actions and follow-up verification.
5. Add a sample review report using fictional data only.
