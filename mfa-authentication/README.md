# Multi-Factor Authentication (MFA)

**Status: Planned**

## Objective

Explain and demonstrate how MFA strengthens account authentication in a personal learning environment.

## Concepts Covered

- Authentication factors
- Something you know, have, and are
- Authenticator apps and security keys
- MFA enrollment and recovery
- Phishing-resistant authentication concepts

## Lab Plan

1. Describe a fictional organization’s authentication risks.
2. Compare password-only sign-in with MFA.
3. Document a safe MFA enrollment and recovery workflow.
4. If using a personal lab, configure an available test environment and record the steps.
5. Document limitations, user impact, and recommended safeguards.
