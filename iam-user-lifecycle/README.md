# IAM User Lifecycle Management

**Status: Planned**

## Objective

Demonstrate how identity access should be managed when an employee joins an organization, changes roles, or leaves.

## Concepts Covered

- Joiner, mover, and leaver (JML) lifecycle
- Account creation, modification, disabling, and removal
- Approval and verification steps
- Least privilege and timely access removal
- Audit trail and documentation

## Lab Plan

1. Define a fictional organization and sample departments.
2. Create a user onboarding checklist and access request template.
3. Document a role-change scenario and the permissions that must change.
4. Document an offboarding scenario, including account disablement and access revocation.
5. Add screenshots or sanitized evidence from a personal lab after performing the steps.
