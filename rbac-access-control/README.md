# Role-Based Access Control (RBAC)

**Status: Planned**

## Objective

Design a basic role and permission model that grants users only the access needed for their responsibilities.

## Concepts Covered

- Roles, users, groups, and permissions
- Role and permission mapping
- Least privilege
- Separation of duties
- Access request and approval

## Lab Plan

1. Create a fictional company with several job functions.
2. List sample resources and permissions.
3. Build a role-permission matrix.
4. Assign fictional users to roles and explain why each assignment is appropriate.
5. Review the matrix for excessive access and document improvements.
